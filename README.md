# کیبورد هزارگی — هزارگی؛ زبان ما، هویت ما

## ساخت APK
GitHub: فایل‌ها را در مخزن بگذارید ← تب Actions ← Build APK ← Run workflow ← فایل APK در Artifacts.
Android Studio: Open ← Build ▸ Build APK(s).

## امکانات
- زبان‌ها: هزارگی (پیش‌فرض)، فارسی، English، العربية — ترتیب حروف مطابق کیبورد مرجع، با ردیف اعداد
- هر حرف هزارگی: ساده، فتحه، کسره، ضمه؛ حرف‌های پنهان (ض غ ظ ژ ذ آ ئ ء ؤ) با نگه‌داشتن کلید
- کشیده‌نویسی: کلید «ـــ» را نگه دارید ← سـ‌ـ‌ـ‌ـلام
- اعداد و نشانه‌ها (دو صفحه)، ایموجی (۱۲ دسته)، استیکر (لباس سنتی، عروسی، روزمره، خوراک، فرهنگ)
- کلیپ‌بورد: متن یا لینک کپی‌شده بالای کیبورد می‌آید؛ یک ضربه = چسباندن (تاریخچه‌ی ۱۵ مورد، فقط در حافظه؛ در فیلد رمز نمایش داده نمی‌شود)
- ساخت استیکر از گالری، ۴ تم، ارتفاع کلیدها، لرزش، صدا، انیمیشن
- بدون تبلیغات؛ متن تایپ‌شده ذخیره یا ارسال نمی‌شود
