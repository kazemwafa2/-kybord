# کیبورد هزارگی — هزارگی؛ زبان ما، هویت ما

نسخه‌ی 1.1.0 (versionCode 2) — Android Studio / GitHub Actions

## ساخت APK
- **GitHub (بدون Android Studio):** فایل‌ها را در مخزن بگذارید ← Actions ← «Build APK» ← فایل در Artifacts. این ساخت آزمون‌های واحد را هم اجرا می‌کند.
- **Android Studio:** Open ← Build ▸ Build APK(s).

## امضا و انتشار (برای به‌روزرسانی از داخل برنامه ضروری است)
۱. کلید ثابت امضا را فقط یک بار در Secrets مخزن بگذارید: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD` (راهنما در فایل جداگانه‌ی کلید).
۲. برای هر انتشار: `versionCode` را زیاد کنید، `versionName` را عوض کنید، فایل `release-notes/vX.Y.Z.md` را بنویسید، سپس
   `git tag vX.Y.Z && git push origin vX.Y.Z`
   ← Workflow «Release» اگر برچسب با versionName نخواند یا کلید امضا نباشد متوقف می‌شود، وگرنه APK امضاشده + `.sha256` + `version.json` را در Releases می‌گذارد.
۳. الگوی نسخه: `v1.0.1`، `v1.0.2`، `v1.1.0` …؛ انتشارهای pre-release به کاربران پیشنهاد نمی‌شوند.
۴. پیش از اعلام عمومی، APK را روی گوشی واقعی نصب و آزمایش کنید.

## سیستم به‌روزرسانی
- تنظیمات ← «به‌روزرسانی»: نسخه‌ی نصب‌شده، دکمه‌ی «بررسی به‌روزرسانی»، سوئیچ بررسی خودکار.
- بررسی خودکار حداکثر روزی یک بار (و هنگام باز شدن تنظیمات هر ۱۲ ساعت)، با کش ۶ ساعته برای محدودیت درخواست GitHub. فقط `releases/latest` مخزن `kazemwafa2/-kybord` خوانده می‌شود.
- نسخه‌ی جدید: پیام با نسخه‌ی فعلی/جدید و تغییرات + «دانلود و نصب نسخه جدید» / «بعداً» (سه روز آرام می‌ماند). در کیبورد هم چیپ «⬆ نسخه جدید» دیده می‌شود.
- دانلود: اندازه و SHA-256 بررسی می‌شود؛ ZIP در صورت وجود استخراج می‌شود؛ نام بسته، versionCode و minSdk فایل کنترل می‌شود؛ سپس نصب‌کننده‌ی رسمی اندروید باز می‌شود (نصب بدون تأیید کاربر در اندروید ممکن نیست). در اندروید ۸+ اگر اجازه‌ی «نصب از این منبع» نباشد، راهنما نشان داده می‌شود.
- تنظیمات و زبان کاربر هنگام به‌روزرسانی حفظ می‌شود (همان شناسه‌ی بسته و همان کلید امضا).
- **توجه:** نسخه‌هایی که قبلاً با کلید debug ساخته و نصب شده‌اند، یک بار باید حذف شوند؛ نسخه‌ی امضاشده با کلید ثابت روی آن‌ها نصب نمی‌شود.
- حریم خصوصی: هیچ متن تایپ‌شده‌ای ارسال نمی‌شود؛ فقط یک درخواست GET به GitHub (آدرس IP برای GitHub دیده می‌شود). با خاموش کردن «بررسی خودکار» هیچ درخواست خودکاری انجام نمی‌شود.

## امکانات
- زبان‌ها: هزارگی (پیش‌فرض)، فارسی، English، العربية — ترتیب حروف مطابق کیبورد مرجع، با ردیف اعداد
- هر حرف: ساده، فتحه، کسره، ضمه (نوشته‌های کوچک زیر حرف)؛ حرف‌های پنهان (ض غ ظ ژ ذ آ ئ ء ؤ) با نگه‌داشتن کلید
- کشیده‌نویسی، اعداد و نشانه‌ها، ایموجی، استیکر، ۴ تم، لرزش/صدا/انیمیشن
- کلیپ‌بورد: نوار چسباندن، تاریخچه‌ی ۱۵ مورد (فقط در حافظه؛ در فیلد رمز نمایش داده نمی‌شود)
- متن طولانی: چسباندن تکه‌تکه (۴۰۰۰ نویسه) در یک ویرایش یکپارچه، بدون سقف طول؛ همه‌ی بخش‌های کلیپ خوانده می‌شود
- ارتفاع و فاصله‌ی کلیدها قابل تنظیم؛ ناحیه‌ی لمس هر کلید کل خانه است و اگر انگشت هنگام برداشتن از کلید بیرون رفته باشد حرفی تایپ نمی‌شود
