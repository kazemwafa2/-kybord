# کیبورد هزارگی — هزارگی؛ زبان ما، هویت ما

## ساخت APK
**روش ۱ — Android Studio:** پوشه را باز کنید (Open) → Build ▸ Build APK(s)
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

**روش ۲ — خط فرمان:** `gradle assembleDebug` (Gradle 8.5 و JDK 17)

**روش ۳ — بدون کامپیوتر:** پوشه را در یک مخزن GitHub بگذارید؛ تب Actions ▸ Build APK
را اجرا کنید و فایل APK را از Artifacts دانلود کنید.

## فعال‌سازی
برنامه را نصب و باز کنید ← «فعال‌کردن کیبورد» ← «انتخاب کیبورد هزارگی».
